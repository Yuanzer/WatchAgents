# Watch4 精简版 — 架构决策与进度（轮次检查点）

## 目标平台事实（调研结论）
- Watch4 = HarmonyOS 4.x（非 NEXT），可 ADB 侧载 Android APK，但兼容层约 Android 12(API31) 量级 → minSdk 34 装不上。
- **minSdk=26 / targetSdk=33 / compileSdk=37**（已写入 app/build.gradle.kts）。Miuix blur 要求 minSdk33，故**弃用 Miuix 全家桶**，UI 用纯 Compose Material3（compose-bom 2025.10.01 已加）。
- 无 GMS；系统 RecognitionService **很可能不存在** → Android SpeechRecognizer 不可靠。内置转文字需自研后端。
- 骁龙 W5 Gen1(ARM64) + ~2GB RAM：本地 Whisper 不现实 → **云端 STT 主方案**（复用 OkHttp/AgentHttpClient），系统 ASR 若有则优先（零成本高质量）。
- 屏幕 466×466 圆屏 ≈ 233dp 宽；内容放内切圆内、边缘留 ~16-20dp。
- 联网搜索原实现=WebView 离屏浏览器（AgentBrowserSession，已随 browser 包删除）；Watch 版需轻量替代（见下"待办"）。
