# Watch4 聊天核心 — 侦察结论(2026)

## 调用链(提交→流式上屏)
UI(HomeScreen/ChatScreen) → AgentChatBody.onSubmit → AgentAppRoot → AgentAppState.sendCurrentMessage
→ launchConversationRun(IO) → RuntimeConfigRepository.currentRuntimeConfig()(Room Provider/Model + DataStore + ReasoningCapabilityResolver)
→ AgentRuntimeClient.run(bindService+Messenger,同主进程) → AgentRuntimeRunExecutor.execute → AgentModelClient.complete
→ AgentPromptBuilder.buildInitialMessages + AgentToolCatalog.build → AgentLoop.run → OpenAiChatCompletionsProvider(SSE)
→ 事件回主线程 → AgentRunEventCoalescer(80ms) → AgentRunMessageProjector → Compose 渲染。
联网仅第 8 步;DB/配置在第 4、10 步。

## 多会话
Conversation ↔ ConversationMessage(CASCADE+唯一索引) ↔ ContextCheckpoint ↔ State(单行 selected)。
DAO 整表 replaceAll 事务。标题:首条消息前缀 24 字;首条时异步调 LLM 精炼(失败回退、不覆盖改名)。
AgentConversationStore.load 启动时 runBlocking(IO) 读 Room 分页。

## Provider/模型/缓存
- DeepSeek: BuiltinProviders id=builtin-deepseek, baseUrl=https://api.deepseek.com(无 /v1, 拼 /chat/completions), apiKey 用户填。
- OfficialModelCatalog: deepseek-v4-pro / deepseek-v4-flash / deepseek-v4-flash-vision-exp。
- 思考: ReasoningCapabilityResolver.catalogCapabilities → flash {low,high,max} 默认 high 可关; pro {high,max}。
  ProviderReasoning.applyDeepSeek: LOW/MEDIUM/HIGH→reasoning_effort=high, XHIGH/MAX→max, OFF→删字段;额外写 thinking:{type}。
- 缓存: OpenAiChatCompletionsProvider.parseUsage: cached = prompt_tokens_details.cached_tokens ?? cache_read_input_tokens ?? prompt_cache_hit_tokens(DeepSeek 官方字段)。
- 直连 DeepSeek 官方 OpenAI 兼容端点,无中间服务。

## 启动/进程
WaApp(UI 进程) + ModuleMain(纯 Xposed 入口,手表版删除)。Runtime 与 UI 同主进程 Messenger 解耦。
AgentAppRoot: 手写传参无 DI,手动导航栈 AppRoute。

## 联网搜索
无搜索 API。browser_use → AgentBrowserSession(离屏 WebView navigate→get_readable) 打开搜索引擎页取正文。
web-research skill 建议 navigate→提取→多源交叉。

## 裁剪路线(建议)
1. 删 ModuleMain / Xposed 初始化(WaApp 已改)。
2. **去掉 Runtime Messenger/overlay/无障碍层**,UI 进程内直调 AgentModelClient.complete(它已是普通阻塞函数)。
   需要 AgentEvent/AgentRunController/AgentRunCancelledException 等纯数据结构 + AgentLoop + 各 Provider。
3. 重写瘦版 ToolExecutor(替代 AgentLocalTools,只留 browser_use / memory / skill 等手表可用工具)。
4. AgentAppRoot 只留 Home/Chat;整个 ui/ 目录重写为圆形屏幕适配的轻量 UI。
5. data/db/provider/config 基本原样保留;Prefs 去 Xposed 部分;RuntimeConfigRepository 去 syncToRemotePreferences。
