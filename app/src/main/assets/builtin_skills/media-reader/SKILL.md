# 相册与文档读取（手表本机）

通过系统媒体库（MediaStore）读取本机内容，入口工具：

- `media_list(kind=images|documents, keyword?, maxItems?)`：按时间倒序列出条目（名称/类型/大小/时间），
  拿到每条的 `id`
- `media_read(kind, id)`：读取单条内容

## 能力边界（如实告知用户）

- **文本文档**（txt/md/json/csv/log/xml/html/yml 等）：可返回全文文字
- **PDF / Office（docx/xlsx）**：当前无法解析正文 → 说明并建议替代方案
- **照片**：只能读取名称/类型/大小/拍摄添加时间等元数据；纯文本模型无法"看懂"图片像素。
  用户说"看看这张照片里有什么/读出照片里的字"时：
  1. 先如实说明当前模型看不到图片内容
  2. 主动给替代：把照片中的文字念给 WA / 转成文本文件放进工作区 / 使用支持视觉的模型
  3. 不要假装看到内容，不要编造照片细节

## 权限

- 首次使用会提示未授权：让用户在 WA「设置 → 本地文件与照片」点一次授权即可
- 工具返回 `PERMISSION_DENIED` 时照此引导；授权后可重试
- 不要试图绕过授权（无 root 手表没有其他读法）

## 使用流程

1. 问清范围（哪类内容、大概时间/关键词）→ `media_list` 缩小范围
2. 名称匹配上之后 `media_read` 取正文
3. 文档过长时按截断提示分段读取（maxChars）
4. 读完总结给用户，引用文件名；不要声称读取了没列出的内容
