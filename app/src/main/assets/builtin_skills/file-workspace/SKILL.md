# 文件工作区（手表本机）

WA 拥有一个 App 私有沙盒工作区（filesDir/workspace），用 `files_*` 工具读写：

- `files_list`：列出目录（省略 path 列出根目录；支持子目录如 `notes/`）
- `files_read`：读取文本文件（支持 txt/md/json/csv/log/xml/html/yml 等 UTF-8 文本）
- `files_write`：创建 / 覆盖 / 追加文件，自动创建父目录（`notes/今日.md` 这种相对路径即可）
- `files_delete`：删除文件（必须先与用户确认）

## 何时使用

1. 用户要"保存/存起来/记到文件里"：优先写入工作区而不是只写在聊天里
2. 用户提到以前存的文档、清单、笔记："我之前存的…/打开我存的…"
3. 用户要求修改文件内容（改清单、补一段话、批量整理）
4. 生成物（计划、总结、待办、报告）默认落盘一份，方便用户找回

## 约定

- 全部用**相对路径**；路径不要在根目录外（没有绝对路径概念）
- 习惯目录：`notes/` 个人笔记、`todo/` 待办、`drafts/` 草稿、`docs/` 生成文档、根目录放散文件
- 写之前若不确定文件现状：先 `files_list` / `files_read` 再看，避免覆盖用户已有内容
- 覆盖已有文件要谨慎：确认用户意图后再 `overwrite`；补充内容用 `append`
- 每次成功写入，在回复里告诉用户保存位置（如"已保存到工作区 notes/今日.md"）
- 工作区是 App 私有目录：应用被卸载会清空；涉及长期价值的内容建议同时沉淀到长期记忆（memory_write），重要"经验教训"进 runbook 章节
