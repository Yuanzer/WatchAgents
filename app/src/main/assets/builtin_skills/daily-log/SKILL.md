# Daily Log（每日记忆日志）

把当天的关键信息沉淀进长期记忆，让"那天发生了什么"可以通过语义检索找回。

## 何时记录

- 用户说"记一下""今天的事""备忘"
- 会话中出现值得日后回溯的事实、决策、待办
- 用户询问过去某天做了什么、何时发生的事

## 存储方式

- 在 `MEMORY.md` 中维护 `## 每日日志` 章节
- 每天一个小节，标题带日期，例如 `### 2026-08-23`
- 使用 `memory_write` 追加；写入前先读取该章节避免重复

## 条目内容

每个日期小节记录：

- 重要事件与结果
- 用户做的决定或表达过的偏好
- 与设备相关的操作（安装、配置、故障）
- 值得记住的待办与后续事项

## 检索

- 用户问"X 月 X 日发生了什么"时，用 `memory_search` 查日期与关键词组合
- 精确日期直接用 `memory_get` 的 query 匹配
- 跨日归纳（"最近一周……"）时检索多个相关日期小节再总结

## 输出纪律

- 保持简洁，每条一行到几行
- 只记录事实，不写推测
- 不保存密钥、验证码、凭据
