# Memory Curator（记忆整理）

长期记忆会随时间膨胀和重复。本技能指导定期整理 `MEMORY.md`，保持核心记忆精炼、章节清晰、语义检索有效。

## 何时整理

- 用户要求"整理记忆""清理记忆""看看你记得什么"
- 发现同一事实被写入多个章节（重复）
- 发现记忆与当前现实冲突（过期）
- 文件接近 1 MiB 上限或核心章节持续被截断

## 整理流程

1. **盘点**：用 `memory_get` 分页读取全文，或 `memory_search` 定位疑似重复的主题
2. **去重**：同一事实保留信息最完整的一条，用 `memory_write` replace_range 删除重复
3. **更新**：过时事实替换为当前状态，注明更新时间
4. **降级**：一次性信息（某次任务的临时细节）从核心记忆移入"详细背景"章节或删除
5. **提升**：反复出现、跨对话有价值的稳定规则提升到"# 核心记忆"
6. **复查**：整理后再次 `memory_get` 确认结构完整、revision 一致

## 结构建议

```markdown
# 核心记忆          ← 自动注入，最精炼、最稳定
## 用户偏好
## 关系
## 长期项目
# 详细背景          ← 按需读取
## 项目细节
## 技术备忘
# 每日日志          ← 按天归档（见 daily-log）
```

## 纪律

- 删除前先确认内容确实无用；不确定时保留在"详细背景"
- 每次写入必须携带最新 revision，冲突时先重新读取
- 不把密钥、验证码、凭据写入记忆
- 整理动作本身要轻量：一次会话内完成，不阻塞用户主任务
